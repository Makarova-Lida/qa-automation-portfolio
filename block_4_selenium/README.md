Цель практической работы
Научиться валидировать состояния элементов с помощью Selenium.



Что нужно сделать
Автоматизируйте тест-кейсы, описанные ниже, для сайта GitHub.



Кейс №1

Шаги:

Откройте страницу https://github.com/microsoft/vscode/issues.
Введите в поиск фильтр in:title.
Введите в поиск какие-то ключевые слова (слова, по которым можно найти любую из задач по названию). Например: bug. 
Нажмите на Enter.
Получите все названия задач.
Проверьте, что каждая из задач содержит в названии слово bug (важно не учитывать регистр, то есть Bug и bug — это одно и то же).


Кейс №2

Шаги:

Откройте страницу https://github.com/microsoft/vscode/issues.
Нажмите на кнопку Author.
Введите в поиск имя bpasero. 
Дождитесь появления в списке нужного автора.
Выберите в выпадающем списке элемент с названием.

Получите все задачи.
Проверьте, что автор всех задач введён в поиск.


Кейс №3

Шаги:

Откройте страницу https://github.com/search/advanced.
В поле языка, на котором написан код, выберите Python.

В поле количества звёзд у репозитория выберите >20000.

В поле с названием файла выберите environment.yml.

Нажмите на кнопку поиска.
Соберите информацию по всем репозиториям.
Проверьте, что в списке отображаются репозитории с количеством звёзд >20000.


Кейс №4

Шаги:

Перейдите на сайт «Онлайн-курсы по программированию от Skillbox».
В блоке фильтров выберите вкладку «Профессия» (tab с текстом «Профессия» в панели фильтрации программ).
Откройте выпадающий список «Длительность» и выберите диапазон обучения от 6 до 12 месяцев.
Откройте выпадающий список «Тематика» и выберите любую доступную тематику.
Проверьте, что в списке отображаются курсы (программы), соответствующие выбранным фильтрам.


Кейс №5

Шаги:

Откройте страницу https://github.com/microsoft/vscode/graphs/commit-activity. 
Наведите мышку на график.

Проверьте, что в отображаемом тултипе находятся ожидаемые вами значения.


Что оценивается
Корректность написания тестов:
действия соответствуют заявленным в задании;
шаги выполнены успешно;
код читаем, в нём нет лишних строк.
Для всех тестов корректно реализованы локаторы, они не слишком длинные и сложные.
Код чистый, нет лишних комментариев, вызовов ненужных методов.
Все ожидания или валидации отрабатывают успешно.
