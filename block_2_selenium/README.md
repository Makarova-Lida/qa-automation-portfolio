Создать два разных файла с настройкой окружения и версиями в них.

Установить все необходимые зависимости: pytest, selenium, chromium
Создать файл с тестами в директории: src/tests
Создать директорию src, а в ней tests
Внутри создать файл для запуска тестов.
Внутри файла написать тесты заглушки (можно с использованием pass)
Настроить один из файлов конфигурации со следующими настройками:
Добавить параметры команды строки при запуске: 
не печатать результат тестирования в лог;
перезапускать упавшие тесты с предыдущего запуска; (дока) Прошу обратить внимание что при запуске тестов из pycharm данный параметр не работает. Лучше воспользоваться make
