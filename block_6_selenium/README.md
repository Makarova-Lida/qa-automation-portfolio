Цель практической работы
Финально настроить тестовый репозиторий для полноценной работы над тестами.

Что нужно сделать
Настройте структуру своего проекта в соответствии с рекомендациями из видео:
Возьмите тесты из предыдущих видео.
В соответствующие директории вынесите:
Все тесты.
Все вспомогательные функции (если их нет, реализуйте вспомогательные функции с действиями на сайте).
Все фикстуры.
Настройте конфигурационные файлы.
Настройте логирование для всего проекта:
Реализуйте шаблон логирования, соответствующий записи 
[2022-07-19 16:32:46,476] INFO - request: Request was sended, 
где request — название файла, в который записывается лог. 
Напишите логи в фикстуре запуска браузера. До запуска и после.
Напишите во вспомогательных функциях логи, описывающие действия.
Настройте более глубокое логирование для allure-репорта:
Все действия, выполняемые Selenium, оберните в шаги.
Для всех тестов укажите названия, описывающие тест, на русском языке.
Оберните тест-сьют в декоратор с названием сьюта, описывающим его, на русском языке.
Настройте статический анализатор flake8:
Укажите размер строки, не превышающий 120 символов.
Исправьте проблемы, которые нашёл анализатор.


Что оценивается
Чистота структуры:
Все тесты, фикстуры, функции в логичных директориях.
Логирование работает корректно и по указанному шаблону.
Логирование в Allure также работает и отображается корректно.
Статический анализатор кода отрабатывает успешно, и все проблемы исправлены.
