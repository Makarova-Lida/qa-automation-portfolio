Цель работы
Научиться понимать принцип тестирования веб-интерфейса.
Что нужно сделать
Для сайта GitHub напишите восемь тестовых сценариев разных видов. Можно быть как авторизованным на сайте, так и нет.

Возможные виды:
компонентные;
функциональные (бизнес-кейс);
интеграционные (кейс на сетевое взаимодействие);
визуальные;
адаптация (мобильный телефон → браузер).
Идеи сценариев можете разрабатывать самостоятельно. 
Рекомендации
Пример для написания тестового сценария можно прочитать на сайте VictorZ.
Что оценивается
Адекватность тестовых сценариев.
Формат написания тестовых сценариев.
Корректность написания тестов: количество верных проверок, последовательность действий, подготовка данных.
Сложность выбранного сценария: пользователю не нужно просто ввести символы в поле и нажать логин.
